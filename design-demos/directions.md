# Leash — three directions (light gate: first screen each, same content, 1440×900)

Spec: one screen where you see your AI agent haggle with seller agents over real products, a scam seller get removed, and the deal settle on PayPal. Audience: hackathon judges watching a <3 min video, then people delegating purchases. Content identical across directions.

## Dir 1 · Security paper
- Logic: best designer, Ootje Oxenaar (Dutch guilder banknotes): security printing as identity.
- Borrowed: guilloché engraving, intaglio navy, seal, rubber stamps; 3-column ledger.
- Hero material: the signed mandate as a passport card, stamps slam on at each checkpoint.
- Boldness: the stamps. Form from content: a mandate is a signed document; trust = security print.

## Dir 2 · Price pit
- Logic: best designer, Experimental Jetset: strict grid, giant grotesk, one signal colour.
- Borrowed: type-as-image, black/white with red only for danger (cap line, attack).
- Hero material: data as image. Giant deal price + a chart where seller offers converge under the red mandate cap; the scam seller's line is cut off.
- Boldness: 200px+ price numerals. Form from content: negotiation is prices moving toward each other.

## Dir 3 · Protocol docs
- Logic: roulette S=14 → web #15 Utility-First Colorful Docs.
- Borrowed: docs-style two-column (prose | code), colour per system, monospace payloads.
- Hero material: every chat line paired with what actually went over the wire (DeepSeek, Channel3, Leash, PayPal), colour-coded.
- Boldness: the paired wire column. Form from content: judges score technical depth; this shows real API calls.
